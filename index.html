Placement automatique

Transparence de la défense

Glissez un pion pour le déplacer à cette étape. Passe : glissez le ballon orange sur le receveur, ou touchez « Passe » puis le receveur. Tir : glissez le ballon dans le but. Une étape est créée automatiquement si besoin. En pointillé : la position à l'étape précédente.

Départ

Départ = placement initial, sans flèche. Placez les joueurs et glissez le ballon vers le joueur qui commence. Pour un déplacement ou une passe fléchés, ajoutez une étape (＋ Étape) : les flèches partent de cette position de départ.
